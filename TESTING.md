# Fold 6 preview check

Current scoped preview: **0.5.7-glass5 / code15**. Hosted device/reboot/physical qualification remains open; see the release notes for exact local/native scope.

The owner reports Play Protect blocks on earlier previews, including code12. Keep Play Protect enabled and record any warning's exact wording; its cause is still unknown.

Record Android/One UI version, cover or unfolded screen, refresh rate and whether Reduced effects is enabled.

1. Install the APK as an update to Arcfold Dev. Keep the existing install and saved layout.
2. Compare Midnight Arc/Aurora and Frost/Pearl on cover and unfolded screens. Check text, glass edges, dock lighting, and Bottom/Left/Right placement. Appearance should show Glass active or the actual fallback reason; record it and try Retry glass if offered. Imported wallpapers should stay selected; removing one returns to the theme wallpaper.
3. Slowly drag up for Library and down for Search. Hold midway, reverse and release a short pull, then try a full pull and a quick swipe. Confirm the view follows your finger and settles correctly; Search should show its field during the pull and bring up the keyboard after opening. Pull Library down at its list top; scrolling back to the top should require a new gesture to dismiss. Confirm the wallpaper remains clearly visible through real blur, without a forced navy/white wash. Check text and control outlines over a busy imported wallpaper too; settings should stay opaque. Try List/Grid, long app names, ordinary list scrolling, edge alphabet scrolling and the last app at the bottom. Watch the entry/return transitions and newly visible icons fading/lifting into place; text and touch positions should stay stable.
4. Create/edit a Library collection. Its membership should affect Library only; Search should still find apps outside it. Recent apps belong to Search only; try Clear and Hide.
5. Search for an app, Wi-Fi, appearance and a published app shortcut when available. Back should first close the keyboard, then return to the source view. Device settings destinations depend on the phone's exported settings activities.
6. Open folders, app menus and Library/Search pickers; switch Dock/Edit controls. Check glass entry/shape changes and rapid dismissal/reopening. Touch and gently tilt the phone to compare lighting; text/icons should stay sharp and cancelled presses must not commit actions. Try Reduced effects too.
7. Fold/unfold while on another Home page, while scrolling Library and with a folder open. Watch for overlaps, lost position, stuck touch input or misplaced popups.
8. Check an existing widget and saved layout after reopening Arcfold and after a phone restart. Reboot continuity remains an open check in this preview. Note any crash or visible delay, plus the exact action and screen.

Use the system's default Home setting to return to your previous launcher. Physical appearance, tilt feel, Samsung keyboard behavior, accessibility and performance are the purpose of this owner test; emulator checks do not establish them.
