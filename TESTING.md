# Fold 6 preview check

Current scoped preview: **0.5.13-home1 / code21**. Physical and wider qualification remain open.

Keep Play Protect enabled. Owner reports the permission change resolved earlier blocking; exact permission/version unspecified, without independent Google classification clearance. Record Android/One UI version, cover/unfolded display, refresh rate and Reduce effects state.

1. Install as an update to Arcfold Dev, retaining the existing install and layout.
2. Choose an image in Customize → Appearance. Check that Android Home uses it too and that a separately selected Lock wallpaper stays unchanged. Cancel selection once, then remove the imported image to return to the theme background.
3. Open Search from Home and Library. Its field should sit at the bottom, immediately above the keyboard. Type, hide the keyboard with Back, and press Back again to return to the source page/Library position. Launch an app and return to check query/position retention and fades.
4. On Home, press Back repeatedly: it should stay on the same Home page. After one edit, repeatedly visit Library/Search and return; the same layout notice should not keep replaying.
5. Compare Home/Edit geometry before changing options. Try all four clock styles, three sizes, alignment/ink and large text. In Edit, drag the clock to top/bottom and left/center/right; cancel another drag and reopen to check persistence. Check both Fold6 displays and side docks.
6. Tap an empty Edit slot, filter the app list and select an app. Confirm exact placement, cancel another selection, and use Undo. Try keyboard focus return after closing the picker and Customize.
7. Hold then drag a Library app onto Home. Pause over a target, hover at the side to change pages, then drop. Try dropping onto another app to create a folder, cancelling a drag and Undo. A second finger should cancel without placing an app. Repeat from Search.
8. Slowly open/close Library and Search, reverse a partial pull and try a quick swipe. Library dismisses downward only when the gesture began at the list top. Search closes upward from its bottom bar or from results already at the bottom. Watch for Home flashes, stuck input, abrupt fades or layout jumps.
9. Check tabbed folder previews and each basic symbol. Drag an app out to Home; cancel another drag and use Undo. Check wallpaper behind system bars. Try cold Library/Search icons, List/Grid, long labels, scrolling and alphabet scrubbing; watch the final drag stretch for a sharp edge. Check glass/readability and Reduce effects.
10. Fold/unfold during navigation and editing; check source page, scroll, dock and touch continuity. Existing widget placements appear as removable unavailable placeholders; widget setup/resize is deferred. Record crashes/delays and the exact action. Reboot continuity remains open.

Use Android's default Home setting to return to your previous launcher. These phone checks assess appearance, feel, Samsung keyboard behavior, accessibility and performance; emulator checks do not establish them.
