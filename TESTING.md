# Galaxy Z Fold 6 preview checks

Current preview: **0.5.23-miku8 / code31**. Physical checks remain open; this page is an owner checklist.

1. Update Arcfold Dev without uninstalling. Check saved apps, folders and layout.
2. Enable **Appearance → Theme → Miku · Halo**. Compare the white Library header, paired icons and labels, receding depth and edge fade on cover/open. The wallpaper should remain completely still.
3. Rotate the wheel both ways. Check the tiny highlight tick with system haptics enabled, and silence with haptics disabled. Launch an app and return to the same selection.
4. Hold empty Home space to edit. Add an app, move it earlier/later, Remove and Undo. Check full names, folders and footer controls with larger text and the keyboard.
5. Open Library and Search, scroll away/back and return from other apps. Hold and scroll through the Library; check that newly visible icons load while your finger remains down. Watch for icon blinking. Try Grid/List, long names, large text, profile/collection controls and tapping card edges. Type in Search: dots should fade through the visible area above the keyboard. Dismiss it with Back and return Home.
6. Hold a Library app still until its contextual menu opens; it should not launch. Hold, then move to start its drag; test cancellation, a drop and Undo. Rotate in Miku Home and confirm the theme remains. Fold/unfold during ordinary use.
7. Check saved wheel/character controls, Reduce effects, Circle spinner, scrolling feel, battery/heat and refresh rate.
8. Check Android Home wallpaper after explicitly changing the background/theme. Lock-screen wallpaper should remain separate.

To leave Arcfold, use **Customize → Choose default launcher**. Report app version, cover/open state and the action that produced an issue. Emulator checks are separate from physical Samsung validation.
