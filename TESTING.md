# Galaxy Z Fold 6 preview checks

Current preview: **0.5.18-miku3 / code26**. Physical checks remain open; this page is an owner checklist.

1. Update Arcfold Dev without uninstalling. Check saved apps, folders and layout.
2. Enable **Appearance → Theme → Miku · Halo**. Compare cover/open card spacing, foreground torso framing and clock readability. The cream footer should reach behind the gesture indicator.
3. Rotate the fan repeatedly in both directions, including with one or two pinned apps. Launch a visible circular icon and return to the same selection. Touching opaque Miku should not launch a hidden card.
4. Adjust wheel/character placement, card spacing/depth, icon gap and blur. Reopen Appearance and restart the app to check saved values. Try Circle spinner and reset defaults.
5. Open Library and Search; type, dismiss the keyboard with Back and return Home. Hold empty space to edit; move/cancel/commit an app and Undo. Fold and unfold during ordinary use.
6. Check Reduce effects, readability, scrolling feel, battery/heat and refresh-rate behavior. Optional music reaction can remain disabled.
7. Check Android Home wallpaper after explicitly changing the background/theme. Lock-screen wallpaper should remain separate.

To leave Arcfold, use **Customize → Choose default launcher**. Report the app version, cover/open state and the action that produced an issue. API37 emulator checks and native images are described in the release; they are separate from physical Samsung validation.
